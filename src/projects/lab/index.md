# Годовой отчёт лаборатории

## Задача

Научно-исследовательская лаборатория федерального вуза собирала годовой отчёт вручную по три-четыре месяца каждый год. Форматирование, вёрстка и вставка библиографии зависели от навыков одного человека.

## Решение

Спроектировал и внедрил систему, где текст, картинки, литературные ссылки и шаблоны оформления разделены, а итоговый документ собирается автоматически:

<figure>
<video src="/assets/lab.mp4" controls="" style="width:100%; max-width:720px;"></video>
</figure>

- Подбор стека: [Obsidian](https://obsidian.md), [Zotero](https://zotero.org), [Pandoc](https://pandoc.org)
- Дизайн процесса автоматической сборки разделов
- Разработка CI/CD пайплайна в GitHub Actions
- Проведение семинаров для обучения команды.

## Результат

- Команда пишет текст — готовый  документ собирается сам
- Библиография, оглавление и вёрстка по ГОСТ — автоматически
- Время сборки: с трёх месяцев ручной работы до 1 минуты автоматической компиляции
