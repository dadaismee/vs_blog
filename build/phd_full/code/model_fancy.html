Параметры

Платежи против Bourgeois

Зелёный столбец — π(B,B) = V/2. Фиолетовый — π(M,B) без санкции (3V/4).
Красный — π(M,B) − δ_eff. Если он ниже зелёного — B защищён от блефа (ESS).

Доли стратегий во времени

Линии: H — красный, D — синий, B — зелёный, Bluff — фиолетовый.
Фон зелёный, когда при текущих V, δ, r выполняется условие ESS для B против Bluff.

Популяция игр и эффективная санкция

Каждый квадрат — игра. Красный — где санкция δ применена, серый — нет.
Эффективная санкция δ_eff = r·δ, δ_min = V/4.
